# Kin Studio

Companion toolkit for [Kindroid](https://kindroid.ai). Character sheets, selfie prompts, group chat, and on-device Kokoro speech. Each person uses their own `kn_` key. Do not share yours.

## Use it

- Web app: https://kin-studio.grok.me
- iPhone: open that link in Safari, then Share → Add to Home Screen. Or install the profile from the latest release.
- Windows: open the site in Chrome and install it as an app.
- Offline desktop pack (includes Kokoro): the latest GitHub release, `Kin-Studio-Desktop.zip`. Unzip, then run `Start Kin Studio.bat`. Leave the window open. Needs Google Chrome.

## Kindroid V2 (October 2026)

V1 retired October 1, 2026. This build matches the public API as documented June 9, 2026, plus the V2 personality screen:

- Push writes name, personality, key memories, response directive, example message, additional context, and current scene (`/update-info`).
- Learned Context (growth, facts, threads), author notes, LLM flair, greeting, and avatar text are copy-only. The public API does not write them.
- Plan caps: Ultra (additional context 2,500, user backstory 1,000) or MAX (5,000 and 2,000).
- Selfie stills: Atelier and Tableau. Video selfies: V4. Equinox V7 and Prism V7.5 are retired. Lyric and Lucid V8 retire December 1, 2026.

API key: Kindroid → Profile Settings → API & advanced integrations.
