Speech
Kindroid audiobook setup

Goal: they talk, you listen, you reply when they finish.

1. Kindroid app
Profile Settings → copy API key (kn_) and each kin’s AI ID. Groups: open the group → copy Group ID from the URL (/chat/group/ID).

2. This app → Settings
Paste the API key → Save. Leave Audiobook mode on.

3. Voices
Engine: Kokoro. Pick a named English voice per kin. First play loads the model once. Assign that voice on the Character tab.

4. Character
Name + AI ID + assigned Kokoro voice → Save. Optional: Push to Kindroid (backstory/memories/directive). Share code is only for cloning, not for chat.

5. Listen
One kin: Chat → pick them → type → Send, or Continue to skip your turn. They speak. When you hear the chime, it’s your turn.
Group: Group tab → Group ID → each member saved with AI ID + voice → Mic, Send, or Continue. Each kin speaks in order. Chime = everyone is done.

Do not tap Kindroid’s own voice button — that bills Kindroid voice. This app speaks API text with Kokoro.
